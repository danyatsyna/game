# Билд Даниила

Личный геймифицированный трекер: месячные сезоны с рангами (Бронза → Легенда), рейтинг по подписчикам, четыре ветки навыков, задачи, трофеи, аналитика.

Один файл `index.html`, без сборки на стороне сервера, данные хранятся в `localStorage` браузера.

## Структура

- `index.html` — готовое приложение (его отдаёт GitHub Pages)
- `src/index.src.html` — исходник; `src/hero.webp` — картинка персонажа
- `demo-data/demo-year.json` — демо-данные за 365 дней (дни как «сколько дней назад»)
- `tools/make_demo_year.py` — генератор демо-данных
- `tools/build.py` — собирает `index.html` из исходника, картинки и демо-данных

## Сборка

```
python3 tools/make_demo_year.py   # только если нужно пересоздать демо
python3 tools/build.py
```

## Демо

Настройки (шестерёнка на главном экране) → «Добавить демо-данные на 1 год».
